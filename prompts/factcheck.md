# 팩트체크

아래 `{{INPUT}}`만으로 검증 가능한 범위에서 한국어 팩트체크 기사를 작성하세요.

1. `검증 대상 주장`, `판정`, `근거`, `확인 범위`를 드러냅니다. 제목과 간결한 본문을 붙입니다.
2. 주장과 확인 자료를 분리하고, 자료가 반박하는 부분과 자료만으로 알 수 없는 부분을 구별합니다.
3. 숫자·날짜·대상·장소를 정확히 옮깁니다. 실제로 하지 않은 독립 검증이나 취재를 했다고 쓰지 않습니다.
4. 판정은 제공된 근거의 강도에 맞추고, 확인되지 않은 예외·미래 계획을 단정하지 않습니다.
5. 입력이 가상 사례이면 결과도 가상 사례라고 표시합니다.

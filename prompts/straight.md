# 스트레이트 기사

아래 `{{INPUT}}`에 제공된 자료만 근거로 한국어 스트레이트 기사를 작성하세요.

1. `제목`, `부제목`, 기사 본문 순서로 씁니다. 리드에서 누가·무엇을·언제 하는지 밝히고, 이후 세부 범위와 예외를 설명합니다.
2. 원문의 날짜·숫자·적용 대상과 제외 대상을 보존합니다. 불확실한 사실은 확인된 것처럼 쓰지 않습니다.
3. 제공되지 않은 취재·반응·예산·발언을 추가하지 않고, 직접 인용은 원문에 정확한 발언이 있을 때만 씁니다.
4. 보도자료 문구를 그대로 나열하지 말고 중복을 덜어 기사 문장으로 정리합니다. 출처는 자료의 성격에 맞게 본문에서 표시합니다.
5. 입력에 실제 기관이나 검증 자료가 없으면 가상 사례임을 지우지 않습니다.

# 가상 취재 질의서 예시

수신: 가온시 중앙도서관 운영 담당 부서

안녕하십니까. 중앙도서관 열람실 운영 장비 유지관리 건에 관한 공개 문서의 금액 차이를 확인하고자 질의드립니다. 2026년 7월 1일 작성된 계약 현황(문서 A)에는 계약금액 2,400만원, 8월 1일 작성된 집행 현황(문서 B)에는 집행액 2,700만원이 기재돼 있습니다. 현재 두 문서의 금액이 서로 다른 이유나 산정 범위는 확인되지 않았습니다.

1. **금액 산정 범위**: 두 금액이 각각 어떤 계약 범위와 기간을 기준으로 산정됐는지 설명해 주십시오.
2. **부가세 포함 기준**: 두 문서의 금액에 부가세가 각각 포함돼 있는지 밝혀 주십시오.
3. **변경계약 여부**: 최초 계약 이후 금액이나 범위가 변경됐다면 변경 시점과 사유를 알려 주십시오. 변경이 없었다면 두 문서에 차이가 난 이유를 설명해 주십시오.
4. **지급 내역**: 문서 B의 2,700만원이 실제 지급액인지, 지급이 이뤄졌다면 날짜와 항목별 금액을 밝혀 주십시오.

계약서, 변경계약서가 있다면 해당 문서, 세금계산서와 지급 증빙의 제공 가능 범위를 알려 주십시오. 회신은 [회신 기한]까지 부탁드립니다.
